# Counter App

Projeto simples de contador desenvolvido com React + Vite utilizando useState.

## Tecnologias utilizadas

* React
* Vite
* JavaScript
* CSS

## Funcionalidades

* Incrementar valor
* Diminuir valor
* Interface clean e responsiva
* Efeitos visuais com hover

## Como executar o projeto

```bash
npm install
npm run dev
```

## Estrutura do projeto

```plaintext
src/
 ├── components/
 │    └── Contador.jsx
 ├── App.jsx
 ├── main.jsx
 └── index.css
```
